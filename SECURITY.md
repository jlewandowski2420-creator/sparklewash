# Security Policy

## Supported version

Only the current production version from the `main` branch is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:
**Security → Advisories → Report a vulnerability**.

Do not open a public issue containing exploit details, credentials, personal data, or access tokens.
Include the affected URL or file, reproduction steps, impact, and any suggested mitigation. We will acknowledge a valid report as soon as practical and coordinate remediation before public disclosure.
